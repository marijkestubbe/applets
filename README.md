# Applets Wetenschappen

Interactieve applets voor de lessen, per module en thema. Online: https://applets-sms.vercel.app

- `index.html` — overzicht (module → thema → applet)
- `fysica/dynamometer.html` — Bepalen van de zwaartekracht
- `fysica/veerkracht.html` — Veerkracht en veerconstante

Nieuwe applet: zet het bestand in de map van de module en voeg een regel toe aan `MODULES` in `index.html`.
